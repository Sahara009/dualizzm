# dualizzm

Магазин работ художницы Лизы. Next.js 15 (App Router), TypeScript, Motion, Lenis, SQLite (встроенный node:sqlite).

## Запуск

```bash
npm install
cp .env.example .env.local   # на Windows: copy .env.example .env.local
# открой .env.local и задай ADMIN_PASSWORD и AUTH_SECRET
npm run dev
```

Скрипты `dev`, `build` и `start` идут через `scripts/next.mjs`: на Node 22.5–22.12 он сам включает встроенный SQLite флагом `--experimental-sqlite`. Предупреждение `ExperimentalWarning: SQLite` в консоли нормальное.

Сайт: http://localhost:3000  Админка: http://localhost:3000/admin

База (`data/dualizzm.db`) и загруженные фото (`data/uploads`) создаются сами при первом запуске. Папка `data` в git не попадает: её нужно бэкапить отдельно.

## Что внутри

- `/` главная: секции идут «стопкой» (следующая наезжает на предыдущую, та темнеет): видео на весь экран, фраза при прокрутке, свежие работы, «В среде», полоса мазков, «Процесс и результат» (рваный край идёт за курсором), «Сотри слой» (стирание краски курсором), «Хроника», знакомство с ASCII-портретом
- `/shop` каталог: фильтры, режимы «сетка» и «список» (в списке картина всплывает у курсора)
- `/shop/[slug]` работа: лупа на фото, кнопка «Купить» в виде пятна синей краски из баллончика (`public/textures/spray-blue.webp`), или «Узнать цену», если цены нет
- `/journal` «Хроника»: блог Лизы в виде газетной полосы, `/journal/[slug]` запись. Записи правятся в админке → «Хроника» (6 черновиков от её лица уже есть)
- `/about` обо мне, о работах, процесс, форма связи и контакты
- `/favorites` избранное (хранится в браузере, без регистрации)
- `/legal/*` оферта, доставка/оплата/возврат, политика ПДн, согласие на обработку ПДн, cookie
- `/admin` работы, заказы, «Хроника», сообщения из формы, настройки (все тексты, контакты, портрет)

Стиль: архив с синими вставками, модерн + брутализм (чёрное меню через «\», синяя бегущая строка LIVE со списком работ, синие плашки, кнопки в квадратных скобках, подписи FILE // ARCHIVE). Акцент `--accent: #1f47ff`, служебный шрифт IBM Plex Mono.

Эффекты: курсор-мишень, уведомление о cookie в виде «терминала хакера», полосы мазков краской с текстом внизу (`public/textures`), заставка (экран «зависает» брутальными вставками на сетке: синие плиты, белые рамки, штрихкоды, счётчик 037%; потом логотип по буквам, трещины и осколки; один раз за вкладку, клик пропускает), надпись dualizzm в футере из синих осколков, которые собираются, когда долистали до низа (`src/lib/wordmark.ts`), бургер-меню на телефоне, синий скроллбар, пиксельная корзина, ASCII-портрет с «линзой», плавный скролл (Lenis), фоновая музыка с кнопкой в шапке. Всё анимированное отключается, если в системе включено «уменьшить движение» (в Windows: Параметры → Специальные возможности → Визуальные эффекты → Эффекты анимации).

## Музыка

Кнопка с полосками в шапке. Играет `public/music/archive-loop.mp3`: временный трек (своя синтезированная петля, без авторских прав). Плейлист задаётся в `src/lib/config.ts` (`MUSIC`): положи mp3 в `public/music` и добавь строку. Браузеры не дают включать звук без действия человека, поэтому музыка стартует по нажатию, а выбор запоминается.

## Тексты и контакты

Тексты от первого лица — черновики, Лиза правит их в админке → «Настройки». Почта `hello@dualizzm.com` и телеграм `@dualizzm` пока моковые. Сообщения из формы «Написать мне» лежат в админке → «Сообщения».

## Документы

Реквизиты продавца для всех документов в одном месте: `src/lib/legal.ts`. Пока там заглушки в квадратных скобках, на сайте они подсвечены жёлтым. Документы — шаблон: перед приёмом платежей их стоит показать юристу.

В заказе две отдельные галочки (оферта и согласие на ПДн): с 01.09.2025 согласие нельзя совмещать с другими условиями. В форме связи — галочка согласия. Сервер не примет заказ или сообщение без них.

Чеки 54-ФЗ через ЮKassa включаются переменной `YOOKASSA_RECEIPTS=1` (для ИП с онлайн-кассой). Самозанятым её не включать: чеки выдаются через «Мой налог».

## Как устроены продажи

- У оригинала один экземпляр. Работа резервируется в момент создания заказа и снова возвращается в каталог, если заказ не оплачен 30 минут или отменён (`RESERVE_MINUTES` в `src/lib/config.ts`).
- Цены считает сервер по базе, цены из браузера игнорируются.
- Способы и цены доставки: `src/lib/config.ts`.

## Оплата

Пока `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` пустые, работает тестовая оплата-заглушка (`/pay/mock/...`). Когда ключи заданы, заказ уходит в ЮKassa.

В личном кабинете ЮKassa укажи адрес уведомлений `https://ТВОЙ-САЙТ/api/payments/yookassa` и события `payment.succeeded`, `payment.canceled`. Статус всё равно перепроверяется запросом к API ЮKassa, а не берётся из вебхука.

Чек (54-ФЗ) формируется в запросе платежа, ставка НДС `vat_code: 1` (без НДС). Если магазин на другой системе налогообложения, поменяй её в `src/lib/payments.ts`.

## Видео на главной

Фон главного экрана: `public/hero/hero.mp4` (1920×1080, без звука, петля) и обложка `public/hero/poster.jpg`. Секция «В среде» на главной: `public/hero/insitu.mp4` и `insitu-poster.jpg` (играет, только когда секция на экране). Чтобы заменить, положи файлы с теми же именами и обнови страницу. Обложка показывается, пока грузится видео, и тем, у кого включено «уменьшить движение».

Фото работ из начальной загрузки лежат в `public/works`. Новые фото через админку сохраняются в `data/uploads`.

## Что нужно заменить перед запуском

- Цены тестовые: «Атриум» 38 000, «Лес» 42 000, «Офис» 35 000 ₽, у «Метро» и «Дома» — «по запросу». Настоящие цены, размеры и технику поставь в админке (`Работы`). Названия рабочие
- Тексты в «Настройки» (черновики от лица Лизы) и настоящие почта/телеграм вместо моковых
- Свой плейлист вместо временного трека
- Акцентный цвет `--accent` и палитра в `src/app/globals.css` подбираются под её работы
- Реквизиты в `src/lib/legal.ts` (ФИО, статус, ИНН, адрес, телефон, срок отправки) и проверка документов юристом
- Уведомить Роскомнадзор о начале обработки персональных данных (уведомление оператора) до запуска

## Выкладка

- **Настоящий магазин — свой сервер (VPS).** Пошагово: `deploy/VPS.md` (Node 24, PM2, nginx, HTTPS, бэкапы). Готовые конфиги: `deploy/ecosystem.config.cjs`, `deploy/nginx.conf`, `deploy/backup.sh`.
- **Netlify — для показа по ссылке (демо-режим).** `netlify.toml` готов, пошаговая инструкция без терминала в `deploy/NETLIFY.md`. Cloudflare Pages и GitHub Pages не подходят: им нужен статический сайт, а здесь сервер с базой. У Netlify нет постоянного диска, поэтому заказы, сообщения, правки и загруженные фото там сбрасываются; админка показывает плашку «Демо-режим».

Папку с данными можно переопределить переменной `DATA_DIR`.
